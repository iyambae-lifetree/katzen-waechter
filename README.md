# Katzen-Wächter

Ein Theme-Mod für die Code-Ansicht der Claude-Desktop-App. Kater Mikesch sitzt oben rechts auf der Fensterbank:

- **Kerze**: brennt herunter, je voller der Chat ist.
- **Napf**: leert sich, je näher das Nutzungslimit (5 Stunden oder Woche) rückt.
- **Mikesch**: döst, während Claude arbeitet, schaut auf, wenn Claude fertig ist, und hebt die Pfote bei einer Frage.
- Kurze Hinweise bei 80 % und 92/95 %, und nach langen Antworten „Mikesch wartet auf dich“.
- Warme Cremefarben, leise Töne in 432-Hz-Stimmung (nach Klick auf den Lautsprecher in der Titelleiste).

A cat theme for Claude Code's desktop app: a candle shows how full the chat is, a food bowl how close the usage limit is, and the cat shows when Claude is waiting for you.

## Installieren / Install

At the prompt of a terminal session:

```
/plugin install katzen-waechter --marketplace iyambae-lifetree/katzen-waechter
```

From a shell:

```
claude plugin install katzen-waechter --marketplace iyambae-lifetree/katzen-waechter
```

In the desktop app, where `/plugin` does not run: click + next to the prompt box, then Plugins, Add marketplace with `iyambae-lifetree/katzen-waechter`, then Add plugin.
